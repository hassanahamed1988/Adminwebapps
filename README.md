# FleetPro Admin — ওয়েব অ্যাডমিন প্যানেল

এটি FleetPro মোবাইল অ্যাপের জন্য একটি আলাদা **ওয়েব অ্যাডমিন অ্যাপ্লিকেশন**। এটি মোবাইল অ্যাপের মতোই একই Firebase ব্যাকএন্ডে (`fleetpromanager-1991`) সরাসরি কানেক্ট হয়, তাই এখানে যা করবেন তা সাথে সাথেই মোবাইল অ্যাপেও প্রতিফলিত হবে।

## এই ভার্সনে কী আছে (v1 — ইউজার ব্যবস্থাপনা)

- **ড্যাশবোর্ড** — পেন্ডিং, অ্যাক্টিভ, ইন-অ্যাক্টিভ (মেয়াদোত্তীর্ণ), ব্লকড ইউজারের লাইভ সংখ্যা
- **পেন্ডিং অনুমোদন** — নতুন নিবন্ধন অনুমোদন (অস্থায়ী পাসওয়ার্ড সেট করে) অথবা প্রত্যাখ্যান
- **অ্যাক্টিভ / ইন-অ্যাক্টিভ / ব্লকড ইউজার তালিকা** — সার্চসহ
- **নতুন অ্যাকাউন্ট তৈরি** — সাইডবারের "নতুন অ্যাকাউন্ট" থেকে সরাসরি সক্রিয় (ENABLED) অ্যাকাউন্ট তৈরি করা যায় — পেন্ডিং ধাপ ছাড়াই, ইউজার আইডি/পাসওয়ার্ড অটো-জেনারেট বা নিজে দেওয়া যায়
- **ইউজার প্রোফাইল** — নাম, ইমেইল, মোবাইল, হোয়াটসঅ্যাপ, রোল, মেয়াদ শেষের তারিখ, দেশ, জাতীয়তা এডিট করা
- **অ্যাকাউন্ট নিয়ন্ত্রণ** — নিষ্ক্রিয়/সক্রিয় করা, ব্লক/আনব্লক করা, স্থায়ীভাবে মুছে ফেলা (সব ট্রিপ, পেমেন্ট, ওয়ালেট ডেটাসহ)
- **লাইট/ডার্ক থিম** — টপবারের ডান পাশে টগল আইকন, ডিফল্ট লাইট থিম, পছন্দ ব্রাউজারে মনে রাখা হয়
- **নোটিফিকেশন আইকন** — টপবারে বেল আইকন, পেন্ডিং অনুমোদনের সংখ্যা ব্যাজ হিসেবে দেখায়, ক্লিক করলে পেন্ডিং তালিকায় নিয়ে যায়
- শুধুমাত্র **ADMIN** ও **MANAGER** রোলের অ্যাকাউন্ট দিয়ে এই প্যানেলে লগইন করা যাবে

## এই ভার্সনে যা নেই (পরের ধাপে যোগ করা যাবে)

ট্রিপ, পেমেন্ট/ওয়ালেট, লোন, মান্থলি ফাইল ব্যবস্থাপনা এবং রেফারেন্স-ডেটা কন্ট্রোল প্যানেল (দেশ, মুদ্রা, ব্যাংক ইত্যাদি) — এগুলো মোবাইল অ্যাপের `ControlPanel.tsx`-এ এখনো বিদ্যমান আছে। প্রয়োজনে পরবর্তী ধাপে এই ওয়েব অ্যাপে যোগ করে দেওয়া যাবে।

## লগইন কীভাবে করবেন

মোবাইল অ্যাপে থাকা যেকোনো **ADMIN** বা **MANAGER** অ্যাকাউন্টের ইউজার আইডি/ইমেইল ও পাসওয়ার্ড দিয়ে লগইন করুন। জরুরি অ্যাক্সেসের জন্য `admin` ইউজারনেম দিয়েও (মোবাইল অ্যাপে যেভাবে কাজ করে ঠিক একইভাবে) লগইন করা যাবে।

## লোকালি চালানো

```bash
npm install
npm run dev
```

তারপর ব্রাউজারে `http://localhost:5174` খুলুন।

## প্রোডাকশনের জন্য বিল্ড করা

```bash
npm run build
```

এটি `dist/` ফোল্ডারে স্ট্যাটিক ফাইল তৈরি করবে, যা যেকোনো স্ট্যাটিক হোস্টিং-এ (Firebase Hosting, Netlify, Vercel) আপলোড করা যাবে। যেহেতু এই অ্যাপটি `HashRouter` ব্যবহার করে, তাই কোনো সার্ভার-সাইড রিরাইট রুল ছাড়াই যেকোনো স্ট্যাটিক হোস্টে কাজ করবে।

### Firebase Hosting-এ ডিপ্লয় (ঐচ্ছিক, একই প্রজেক্টে)

```bash
npm install -g firebase-tools
firebase login
firebase init hosting   # public directory: dist
npm run build
firebase deploy --only hosting
```

## ⚠️ নিরাপত্তা সম্পর্কে গুরুত্বপূর্ণ নোট

বর্তমানে আপনার Firestore সিকিউরিটি রুলস (`firestore.rules`) সম্পূর্ণ উন্মুক্ত:

```
allow read, write: if true;
```

এর মানে API কী (`firebase-config.json`) হাতে থাকলে যে কেউ ডাটাবেস পড়তে/লিখতে পারবে — এটি শুধু এই ওয়েব অ্যাপের সীমাবদ্ধতা নয়, বরং আপনার প্রজেক্টের বিদ্যমান কনফিগারেশন (মোবাইল অ্যাপও একই রুলস ব্যবহার করে)। প্রজেক্টে ইতিমধ্যে একটি হার্ডেন্ড রুলসের ড্রাফট আছে (`security_spec.md`)। এই ওয়েব অ্যাডমিন অ্যাপটি পাবলিকলি ডিপ্লয় করার আগে অন্তত admins/users কালেকশনে role-ভিত্তিক Firestore রুলস চালু করার পরামর্শ থাকলো, যাতে অননুমোদিত কেউ সরাসরি ডাটাবেস এডিট করতে না পারে।

## প্রজেক্ট স্ট্রাকচার

```
src/
  services/       Firebase, auth, encryption — মোবাইল অ্যাপের সাথে সামঞ্জস্যপূর্ণ
  contexts/       Auth, Users (ডেটা+CRUD), Toast, Theme (লাইট/ডার্ক)
  styles/         controls.ts — ইনপুট/সিলেক্টের স্ট্যান্ডার্ড সাইজ (নিচে দেখুন)
  components/     Sidebar, Topbar, StatCard, UserListCard, ConfirmDialog ইত্যাদি
  pages/          Login, Dashboard, UserListPage, UserDetail, NewAccount
```

## ইনপুট বক্সের স্ট্যান্ডার্ড হাইট

সব টেক্সট ইনপুট, সিলেক্ট এবং সার্চ বার একই হাইটের (44px / `h-11`, সার্চ বারের হাইট) — এটা `src/styles/controls.ts`-এ একটাই জায়গায় সংজ্ঞায়িত:

- `inputCls` — সাধারণ ইনপুট/সিলেক্টের জন্য (ডিফল্ট টিল ফোকাস-রিং সহ)
- `inputBaseCls` — শুধু সাইজ/শেপ, ফোকাস-রিং কালার ছাড়া (যেমন ডিলিট কনফার্মেশনে লাল রিং দরকার হলে)
- `inputWithIconCls` — বাম পাশে আইকন থাকা ইনপুটের জন্য (সার্চ বার)
- `CONTROL_HEIGHT` — শুধু হাইট ক্লাসটা লাগলে (কাস্টম স্টাইলের ইনপুটে, যেমন লগইন পেজ)

**নতুন কোনো ইনপুট বক্স তৈরি করলে এখান থেকেই ইম্পোর্ট করে ব্যবহার করুন**, নতুন করে হাইট লিখবেন না — এতে ভবিষ্যতে পুরো অ্যাপে হাইট এক থাকবে। হাইট বদলাতে হলে শুধু এই একটা ফাইলেই বদলাতে হবে।
